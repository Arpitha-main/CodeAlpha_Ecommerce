# 🌷 Arpitha E-Commerce Website

A Django-based e-commerce website with product management, search, categories, shopping cart, wishlist, checkout, orders, authentication, and stock management.

## ✨ Features

- 👤 User registration and login
- 🛍️ Product listing
- 🔎 Product search
- 🗂️ Category filtering
- 📦 Product stock management
- 🛒 Shopping cart
- ➕ Increase cart quantity
- ➖ Decrease cart quantity
- ❤️ Wishlist
- 💳 Checkout
- 📋 Order history
- 🖼️ Product image upload
- ⚙️ Django admin panel
- 🌷 Responsive floral-themed interface

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
